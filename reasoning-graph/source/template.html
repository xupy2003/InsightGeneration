Reasoning Graph Pilot

Four ICPC World Finals problems · 40 graded solver traces · ReasoningGraph Ver2

Each graph is an AND–OR graph of intermediate conclusions for one problem, built by an explorer model from the statement alone; a route into END is a solution family whose program the judge accepted, and the END → CODE edge carries the implementation hazards. A grader then reads each solver trace and marks every node established, wrong, working or absent, each with a verbatim quote. Pick a trace to see the path it took through the graph and where it got stuck. Hover a node for its full statement, click it for the accept criteria and the quoted evidence; drag to pan, scroll to zoom.
