Insight evolution on one problem

An insight is a cut on the reasoning graph: the nodes of a solution route the model does not reach on its own. The engine adds them one node per round, measures every round with real two-hour solver runs, and grades those runs against the same graph. These figures are that record — the same graph, once per condition, coloured by what the runs actually established.

The problem is one the human editorial does not unlock for this model: five editorial runs solve none of them, and the editorial argues a different route into END than the one this model is closest to. Watch the black outline — the node where the runs get stuck — move down the route until it reaches END and the submission is accepted.
